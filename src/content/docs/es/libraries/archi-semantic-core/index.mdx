`@cda/archi-semantic-core` es la librería fundacional del ecosistema CDA:
lee los archivos de modelo `.archimate` nativos de Archi y expone su
semántica a través de un `ArchiModel` pequeño y tipado.

## ¿Qué es?

Un analizador TypeScript del formato nativo `.archimate` utilizado por el
editor de escritorio [Archi](https://www.archimatetool.com/) — tanto la
variante de XML plano como la de archivo zip. Sin reinterpretación, sin
normalización con pérdida: un modelo significa lo que la herramienta de
modelado almacenó.

## ¿Por qué usarla?

Porque sus pipelines, reglas de gobernanza y herramientas necesitan la
arquitectura como **datos tipados y validados** en lugar de un formato de
archivo cerrado. El principio central de CDA es la fidelidad por encima de
la conveniencia — la API preserva la semántica nativa y documenta sus
límites con honestidad.

## Instale

```sh
npm install @cda/archi-semantic-core
```

Requisitos: Node.js `^20 || ^22 || >=24`, solo ESM. Los tipos de TypeScript
están incluidos en el paquete; no se necesita ningún `@types/*` aparte.
Consulte [Instalación](/es/libraries/archi-semantic-core/getting-started/installation/).

## Véala funcionando

Analice un modelo, lea sus elementos y valídelo en pocas líneas:

```ts
import { parseArchiModel, validateArchiModel } from '@cda/archi-semantic-core';

const model = parseArchiModel(xmlText);
const { valid, errors } = validateArchiModel(model);

model.elements.map((e) => e.type); // ["BusinessActor", ...]
```

Ejecute el recorrido completo en unos cinco minutos:
[Inicio rápido](/es/get-started/quick-start/).
